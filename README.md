# Yalova Dijital – Telegram Haber Girişi

yalovadijital.com için WordPress eklentisi.

- Telegram botundan gelen başlık, metin ve fotoğrafları taslak haber olarak ekler; kategori, etiket, SEO ve tagline alanlarını doldurur. Haberler yalnızca Telegram'daki **YAYINLA** butonuyla yayınlanır.
- Dikey fotoğrafları bulanık arka planla yatay kareye oturtur.
- Ana sayfa manşeti: `[yd_manset adet="10"]`
- Nöbetçi eczane listesi: `[yd_nobetci_eczane]`
- Story ve Köşe Yazarları verisini sayfayla birlikte gönderir (hızlı açılış).

## Güncelleme

Yeni sürüm için `yd-telegram-haber.php` içindeki `Version:` numarası artırılıp ana dala (main) gönderilir. Site deponun ana dalındaki sürüm numarasını 3 saatte bir kontrol eder; numara yüksekse Eklentiler sayfasında "Şimdi güncelle" çıkar. Hemen kontrol için: Ayarlar → Telegram Haber → "Güncellemeleri şimdi denetle".
